# 🐍 Python Mini Projects

A collection of beginner-to-intermediate Python projects created to practice and strengthen core Python programming concepts, problem-solving skills, automation, and basic application development.

This repository contains hands-on projects covering **Python fundamentals, file handling, games, utilities, data processing, automation, and basic application development**.

## 📌 Projects

### 🧮 Utility & Calculator Projects

| Project                        | Description                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------- |
| **Simple Calculator**          | Performs basic arithmetic operations such as addition, subtraction, multiplication, and division. |
| **BMI Calculator**             | Calculates BMI based on height and weight and provides a BMI category.                            |
| **Bill Splitter**              | Calculates how much each person needs to pay when splitting a bill among friends.                 |
| **Simple Interest Calculator** | Calculates simple interest and total amount using principal, rate, and time.                      |
| **Currency Converter**         | Converts Indian Rupees into different currencies using predefined exchange rates.                 |
| **Multiplication Table**       | Generates a multiplication table for a user-defined number.                                       |
| **Prime Number Checker**       | Checks whether a given number is prime.                                                           |

### 📊 Data & Productivity Projects

| Project             | Description                                                        |
| ------------------- | ------------------------------------------------------------------ |
| **Expense Tracker** | Records daily expenses and calculates total spending.              |
| **Grade Analyzer**  | Calculates total marks, average marks, and assigns grades.         |
| **Word Counter**    | Counts words and characters from user-provided text.               |
| **To-Do List App**  | Console-based application for creating and managing tasks.         |
| **Reminder App**    | Allows users to create reminders with a specified time delay.      |
| **PDF Compare**     | Compares PDF files using byte-level and extracted-text comparison. |

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/ro9899/python-mini-projects1.git
```

2. Navigate to the project directory:

```bash
cd python-mini-projects1
```

3. Run any Python project:

```bash
python filename.py
```

For example:

```bash
python simple_calculator.py
```
